## What this is

`render-component` is a Rust CLI that renders a **single UI component** in the browser. Base target is **Angular** (`*.component.ts`, `*.module.ts` + templates/SCSS); React (`.tsx`), Svelte (`.svelte`), and Vue (`.vue`) are planned later — keep file parsing and serving extensible per framework.

Intended flow (owner's spec, **not yet implemented**):
1. Navigable file explorer: open folders, move selection (keyboard-driven).
2. Component source files are visually highlighted in the explorer.
3. Selecting a component starts a dev server on a **free port** that renders ONLY that component, including all its imports (SCSS, templates, etc.).
4. If the server is already running, selecting another component **replaces the current view** instead of restarting.
